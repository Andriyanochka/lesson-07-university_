# Система університету (TypeScript)

Навчальний проєкт: студенти, викладачі, курси, групи та факультет.
Показує основи ООП у TypeScript: класи, наслідування, інтерфейси, дженерики.

## Як запустити

```
npm install
npm start
```

Потрібен встановлений [Node.js](https://nodejs.org). Перевірка типів: `npm run typecheck`.

## Файли (папка `src`)

| Файл | Що в ньому |
| --- | --- |
| `contracts.ts` | Інтерфейси та типи: `Identifiable`, `Grade`, `IRepository` |
| `person.ts` | Абстрактний клас `Person` (людина) з перевіркою email |
| `student.ts` | `Student`: оцінки та середній бал |
| `teacher.ts` | `Teacher`, `Professor`, `AssociateProfessor`: розрахунок зарплати |
| `course.ts` | `Course`: курс із викладачем |
| `academic-group.ts` | `AcademicGroup`: група студентів із куратором |
| `faculty.ts` | `Faculty`: факультет, який створює групи |
| `repository.ts` | `InMemoryRepository`: сховище об'єктів у пам'яті |
| `main.ts` | Демонстрація: запускає все разом |

## Основні ідеї 

- **Наслідування:** `Student` і `Teacher` є різновидами `Person`, тому мають спільні ім'я, прізвище та email.
- **Абстрактний клас:** `Person` не можна створити напряму, він лише основа для інших класів.
- **Поліморфізм:** `Professor` і `AssociateProfessor` по-різному рахують зарплату, хоча метод викликається однаково.
- **Інкапсуляція:** оцінки та email приховані (`private`) і змінюються лише через методи з перевіркою.
- **Агрегація:** `Course` та `AcademicGroup` отримують готових викладачів і студентів. Ті існують окремо і не зникають разом із курсом чи групою.
- **Композиція:** `Faculty` сам створює свої групи (`createGroup`). Група належить факультету.
- **Інтерфейс:** `IRepository` описує, що вміє сховище (`save`, `findById`, `findAll`, `delete`).
- **Дженерик:** `InMemoryRepository<T>` працює з будь-яким типом, який має `id`. Наприклад, `InMemoryRepository<Student>`.

## Що виведе програма

1. Викладачі та їхні зарплати (Професор: 30000, Доцент: 20000).
2. Створення групи на факультеті.
3. Оцінки студентів і середні бали (Іван: 91, Анна: 95, група: 93).
4. Збереження, пошук і видалення студентів у репозиторії.
5. Помилка при неправильному email.
